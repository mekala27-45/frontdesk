# Frontdesk portfolio release

Fictional clinic appointment logistics with a shared Meta/simulator ingestion engine, transactional scheduling, durable conversation state, deterministic safety tools, calendar adapters and a static operations console.

The public GitHub Pages showcase adds searchable scenarios, stepped tool-call replays, expected-versus-observed contracts, concurrency and daylight saving visualizations, implementation links, and downloadable verified evidence. It requires no login or live backend. Publication restores the relational snapshot and verifies the public JSON before deploying.

The repository contains locally measured Postgres tests and a browser walkthrough. A public booking API, real Meta device round trip and live Google Calendar delivery remain unverified. Review RESULTS.md and the deployment runbook before describing integration status.
